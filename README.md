# ぺにょったー

ぺぇのつくった Android 向けの Nostr クライアント「ぺにょったー」の配布ページです。うにゃぴ。

## インストール

1. [Releases](https://github.com/petansayu/penyotter-releases/releases) を開き、いちばん上（最新）の `Penyotter-<版>.apk` をダウンロードします。
2. ダウンロードした APK を開いてインストールします。
   - 「この提供元のアプリを許可」などと聞かれたら、許可してください（ブラウザやファイルアプリに、アプリのインストールを許可する設定です）。
   - Play プロテクトの確認が出ることがあります。その場合は「詳細」から「インストールする」を選んでください。
3. Android 9 以上で使えます。

## はじめかた

最初の画面で選びます。

- **はじめる**: 新しい Nostr アカウントを作ります。
- **アカウントを持っている**: 秘密鍵（nsec / ncryptsec）か署名アプリ（Amber など）でログインします。
- **見るだけで使う**: 公開鍵（npub）や「名前@ドメイン」を入れて、閲覧だけをします。

## 更新のしかた

新しい版の APK をダウンロードして、そのままインストール（上書き）してください。アカウントや設定はそのまま残ります。アプリからの自動更新はありません。

## 大事なこと

- **秘密鍵はスマホの中にだけ保存されます。** アプリを消したりスマホを替えたりすると、アプリの中の鍵はなくなります。「設定」→「暗号化秘密鍵を作成」（または「秘密鍵をコピー」）で、必ずバックアップしてください。
- 投稿には「ぺにょったーから投稿」というクライアント情報が付きます。付けたくない場合は「設定」でオフにできます。
- 個人がつくっているアプリです。不具合があるかもしれません。

## ご利用にあたって

- ぺにょったーは、個人が作っている Nostr クライアントです。無料・無保証で提供しています。不具合などで生じた損害について、作者は責任を負えません。

- 秘密鍵（nsec）はアカウントそのものです。なくすと元に戻せず、他人に知られるとアカウントを使われてしまいます。必ず自分でバックアップし、誰にも教えないでください。

## プライバシー

- ぺにょったーは、作者や作者のサーバーに情報を送りません。利用状況の収集や広告もありません。
- 通信するのは、設定したリレー、表示する投稿の作者が使うリレー、画像投稿先、表示する画像やリンク先、NIP-05 の確認先などです。通信先には、IP アドレスなどが伝わります。
- 秘密鍵は端末の中で暗号化して保存します。署名アプリやリモート署名でログインした場合、秘密鍵はこのアプリに渡りません。
- 下書き・一覧の履歴・キャッシュは、この端末の中にだけ保存されます。
