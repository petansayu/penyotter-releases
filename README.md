# ぺにょったー

ぺぇのつくった Android 向けの Nostr クライアント「ぺにょったー」の配布ページです。うにゃぴ。

## インストール

1. [Releases](https://github.com/petansayu/penyotter-releases/releases) を開き、いちばん上（最新）の `Penyotter-<版>.apk` をダウンロードします。
2. ダウンロードした APK を開いてインストールします。
   - 「この提供元のアプリを許可」などと聞かれたら、許可してください（ブラウザやファイルアプリに、アプリのインストールを許可する設定です）。
   - Play プロテクトの確認が出ることがあります。その場合は「詳細」から「インストールする」を選んでください。
3. Android 9 以上で使えます。

## はじめかた

最初の画面で選びます。

- **はじめる**: 新しい Nostr アカウントを作ります。
- **アカウントを持っている**: 秘密鍵（nsec / ncryptsec）か署名アプリ（Amber など）でログインします。
- **見るだけで使う**: 公開鍵（npub）や「名前@ドメイン」を入れて、閲覧だけをします。

## 更新のしかた

新しい版の APK をダウンロードして、そのままインストール（上書き）してください。アカウントや設定はそのまま残ります。

0.200.0 からは、新しい版が出るとアプリが「新しい版があります」と知らせて、この配布ページを開けます（1 日 1 回確かめます。「設定」→「このアプリについて」で止められます）。

1.1.0 からは、そのお知らせの「更新する」を押すと、アプリが APK をダウンロードして Android のインストール画面を開きます。ダウンロードした APK は、リリースに書いた SHA-256 と同じときだけ使います。インストールは、Android の画面で自分で「更新」を押して行います。はじめての 1 回だけ、ぺにょったーに「アプリのインストール」を許す設定が出ます。

## 大事なこと

- **秘密鍵はスマホの中にだけ保存されます。** アプリを消したりスマホを替えたりすると、アプリの中の鍵はなくなります。「設定」→「暗号化秘密鍵を作成」（または「秘密鍵をコピー」）で、必ずバックアップしてください。
- 投稿には「ぺにょったーから投稿」というクライアント情報が付きます。付けたくない場合は「設定」でオフにできます。
- 個人がつくっているアプリです。不具合があるかもしれません。

## ご利用にあたって

- ぺにょったーは、個人が作っている Nostr クライアントです。無料・無保証で提供しています。不具合などで生じた損害について、作者は責任を負えません。
- Nostr への投稿・リアクション・プロフィールなどは公開され、多くのリレーに複製されます。削除を依頼しても、すべてのリレーやアプリから消えるとは限りません。
- 秘密鍵（nsec）はアカウントそのものです。なくすと元に戻せず、他人に知られるとアカウントを使われてしまいます。必ず自分でバックアップし、誰にも教えないでください。

## プライバシー

- ぺにょったーは、作者や作者のサーバーに情報を送りません。利用状況の収集や広告もありません。
- 通信するのは、設定したリレー、表示する投稿の作者が使うリレー、画像投稿先、表示する画像やリンク先、NIP-05 の確認先などです。通信先には、IP アドレスなどが伝わります。
- 秘密鍵は端末の中で暗号化して保存します。署名アプリやリモート署名でログインした場合、秘密鍵はこのアプリに渡りません。
- 投稿には初めから「ぺにょったーから投稿」というクライアント情報（NIP-89）が付きます。設定で外せます。
- 下書き・一覧の履歴・キャッシュは、この端末の中に保存されます。下書きを「リレーに保存」したときだけ、暗号化してリレーにも置きます（あなただけが読めます）。
- 新しい版が出ていないか、1 日 1 回 GitHub の配布ページに問い合わせます（IP アドレスが伝わります）。「このアプリについて」の「更新」で止められます。「更新する」を押したときは、配布ページから新しい版の APK をダウンロードします。
- 翻訳は、スマホの中で行います。投稿の中身をどこにも送りません。翻訳のモデルをダウンロードするときだけ、Hugging Face に IP アドレスが伝わります。
- 知らない人から DM が届くと、その人をフォロー中の人がフォローしているかを、読み込みリレーに問い合わせます。リレーには、その人に関心があることが伝わります。
- プロフィールに Lightning アドレスを設定していると、届いた zap が本物かを確かめるため、開いたときに 1 回そのサーバーに問い合わせます（IP アドレスが伝わります）。

## 技術資料

アプリが Nostr の仕様をどう使っているか（どのリレーから何を読み、どんなイベントをどこへ送るか、NIP をどう解釈しているか）を、[技術資料](design/README.md) にまとめています。使い方の説明ではなく、NIP を読んだことがある人や、ほかのクライアントを作っている人に向けたものです。

## 翻訳（1.1.0 から）

「その他」→「翻訳」で、翻訳のモデル（約 550 MB）をダウンロードすると、ほかの言語の投稿を日本語に、自分の投稿をほかの言語に訳せます。訳すのはスマホの中です。64 ビットのスマホで、メモリが 3 GB 以上のときに使えます。

翻訳には、株式会社 Preferred Networks の [PLaMo 3 Translate](https://huggingface.co/pfnet/plamo-3-translate-0.8b-GGUF) を、[llama.cpp](https://github.com/ggml-org/llama.cpp) で動かして使っています。モデルはアプリに入っておらず、ダウンロードの前に [PLaMo コミュニティライセンス](https://plamo.preferredai.jp/info/plamo-community-license-ja) に同意していただきます。
